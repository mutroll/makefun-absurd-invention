## The pitch

> The Sigh Charger: a phone charger that runs entirely on the long sigh you make when your battery hits 1%, converting pure exasperation into a full charge by morning.

## How it works

`main.py` (Python 3.13 stdlib only, deterministic, no network, no randomness) writes the one-sentence pitch to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out python3 main.py
cat /tmp/out/entry.txt
```
